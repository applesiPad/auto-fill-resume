# 简历自动填写助手 - Resume Auto Filler

Chrome / Edge 浏览器插件，一键将个人简历信息智能填入求职网站表单。

## 功能特性

- **五层填写流水线** — 平台适配器 → 规则评分 → LLM 语义映射 → 纠错学习，层层降级（详见下方架构）
- **央国企网申专项** — 兼容 WebForm 老系统（`ctl00$...` 无语义命名/`__doPostBack`）、table 布局 label、WdatePicker/My97/laydate 日期控件、UEditor/KindEditor 富文本、iframe 嵌套表单、懒加载下拉框
- **LLM 智能识别（L2）** — 规则识别不了的字段（生源地/政治面貌等"体制内"长尾），把字段结构与选项（**不含个人信息**）发给 AI 做语义映射；按表单签名缓存，每个表单只调用一次
- **纠错学习（L4）** — 填写后你手动修正过的字段会自动学习，该站点下次直接用修正值；支持导出/导入适配包分享
- **智能识别** — 多信号加权评分，自动匹配表单字段（name/id/label/placeholder 等 15+ 信号源）
- **多条目填写** — 教育经历、工作/实习、项目、竞赛/荣誉、证书/资质均支持多条添加
- **点击新增才出表单？也能填** — 教育经历/实习/项目等区块初始为空、只有"新增"按钮的页面，自动点击新增揭示表单：行内追加卡片直接填写；**弹窗模式**自动完成"新增 → 弹窗填写 → 点确定落列表 → 再新增录下一条"的完整循环
- **开放题自动作答（v1.7）** — 本地"题库"模糊匹配网申自定义题（是否服从调剂等，零网络）；"为什么选择我行"类长题可由 AI 起草（显式开启，橙色高亮待核对）
- **附件自动上传（v1.7）** — 证件照/身份证/简历附件统一管理，照片自动压缩 ≤200KB，遇到对应上传字段自动提交（DataTransfer 直写，无弹窗）
- **Shadow DOM 穿透（v1.7）** — 兼容 Web Components 门户，表单在 shadow root 内照样识别填写
- **反馈闭环面板（v1.7）** — 每次填写后展示报告：AI 填写项点击定位核对；未识别字段**手动指认一次即写入本站适配层**，下次自动生效
- **框架兼容** — 支持 React、Vue 等前端框架的表单，自动触发合成事件
- **自定义组件** — 兼容 Ant Design、Element UI、Arco Design 等 UI 库的日期选择器和下拉框
- **快捷键** — `Alt+Shift+F` 一键填写当前页面
- **数据管理** — 自动保存、JSON 导入/导出，数据存储在浏览器本地
- **双浏览器** — 同时兼容 Chrome 和 Edge

## 安装使用

### 1. 下载代码

```bash
git clone https://github.com/erdayi/auto-fill-resume.git
```

### 2. 加载插件

**Chrome:**
1. 打开 `chrome://extensions/`
2. 右上角打开 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择项目文件夹 `auto-fill-resume`

**Edge:**
1. 打开 `edge://extensions/`
2. 左下角打开 **开发人员模式**
3. 点击 **加载解压缩的扩展**
4. 选择项目文件夹 `auto-fill-resume`

### 3. 填写个人信息

- 点击浏览器右上角插件图标，打开弹窗
- 在 5 个标签页中填写你的信息：基本信息 | 教育经历 | 工作/实习 | 项目/竞赛 | 其他
- 数据会自动保存

### 4. 一键填写

- 打开任意求职网站的表单页面
- 点击插件弹窗中的 **一键填写** 按钮
- 或使用快捷键 `Alt+Shift+F`

## 技术原理

### 五层填写流水线（v1.5+）

填写时按优先级逐层解析字段，高层未命中自动降级到下一层：

```
L4 纠错学习   用户修正一次 → 该站点该字段永久生效（storage 本地保存）
L0 平台适配   URL/DOM 指纹识别北森/大易/国聘/通用表格布局/WebForm 系统 → 确定性规则
L1 规则评分   15+ 信号源 × 60 个字段匹配器（关键词/精确/否定词）加权打分，阈值 ≥8
L2 LLM 映射   规则未命中的空字段 → 序列化（label/选项/分区，不含个人信息）→ AI 返回
              字段映射 + 置信度 → 白名单校验后填写；按表单签名缓存，每表单只调用一次
```

- **置信度可视化**：绿色高亮 = 高置信；橙色高亮 = LLM 填写，提示用户重点核对
- **隐私红线**：发往 LLM 的只有表单结构信息（字段名、选项文本），永远不含用户简历值
- **兼容老系统**：WdatePicker/My97/laydate 日期控件直接写值并触发 inline `onchange`（`__doPostBack` 链）；UEditor/wangEditor/KindEditor 富文本走官方 API 同步隐藏 textarea；懒加载下拉在聚焦后自动重试匹配

### 经典机制（v1.x 延续）

1. **值设置** — React 内部 onChange 直调 → execCommand 模拟输入 → 原生 setter + `_valueTracker` 重置，三层降级
2. **多条目** — 检测页面分区（教育/工作/项目等），按容器分组填写；区块为空时自动点击"新增"按钮揭示表单——行内追加直接填，弹窗模式自动"填写→确定→关闭→下一条"循环（弹窗确认仅限我们自己点开的弹窗内部，绝不触碰页面级提交按钮）
3. **自定义组件** — 识别 Ant Design、Element UI 等 UI 库的日期选择器和下拉框，模拟交互操作
4. **iframe** — `all_frames: true` 注入，嵌套 iframe 表单同流程填写
